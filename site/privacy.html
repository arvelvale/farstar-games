远星游戏工作室

隐私政策与说明

更新日期：2026 年 11 月 16 日

1. 工作室官网说明

本网站由远星游戏工作室（Farstar Games）运营并托管于 GitHub Pages，仅作为工作室与作品介绍的纯静态页面，不提供用户注册或登录，也不设置第三方统计、广告追踪或营销 Cookie。

访问本页面时，托管平台 GitHub 可能出于安全防护与网络服务需要记录基础连接日志（如 IP 地址），相关处理遵循 GitHub 官方隐私声明。

2. 离线游戏应用（含《火柴三国：群英传》当前原型）

工作室当前开发中的《火柴三国：群英传》采用离线本地运行设计，不收集用户的姓名、手机号、精确位置、通讯录或设备识别码，也不向工作室自建服务器回传游戏数据。

游戏设置及本地记录（如适用）仅保存在玩家设备本地存储中，卸载应用或清理应用数据即可删除。

3. 后续联网或平台接入的更新原则

如后续具体游戏版本接入渠道账号登录、云存档、联机服务或第三方 SDK，工作室将在对应版本发布前同步更新本隐私政策或提供分游戏独立隐私协议，并在应用内明示所需权限与数据用途。

4. 联系我们

如有关于本隐私政策或游戏产品的疑问与建议，可通过开发者的公开 GitHub 主页（github.com/arvelvale）或 X（@ArvelVale）联系。
